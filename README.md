# To-Do List Application
A Java-based To-Do List application designed to help users manage their personal and professional responsibilities, improving productivity and reducing stress. This project was built as a group assignment by group 7 for the Software Design 1 module at Cape Peninsula University of Engineering Technology using Java Swing. 

# Features
- Add, delete, and prioritize tasks
- Set due dates and mark items as complete
- Organize tasks by categories (e.g. Personal, Work)
- Input validation and error handling

# Tech
- Language: Java 
- GUI Framework: Java Swing
- IDE: Apache Netbeans

# Technical Implementation
As per the project brief, this application implements the following Java concepts:
- Constructors: Used for initializing Task objects.
- Modifiers: Used appropriately.
- Control Statements: Used for logic.
- Java Frame Forms: The GUI is built using Java Swing.

# How to Run the Application
# Pre-requests
- Java Development Kit (JDK) installed.
- An IDE or the Java command line.

# Steps
1.Download this repository.
2. Open the project in an IDE.
3. Locate the main file.
4. Run the application to launch the Java Swing interface.
